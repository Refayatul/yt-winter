Amtrak 501 derailed onto Interstate 5 near DuPont. The cause: overspeed on a curve without active positive train control and with an inadequately trained engineer.

Failure chain: First run on new route → Engineer unfamiliar → No active ptc → Curve at 78 mph → Cars fall onto I-5
