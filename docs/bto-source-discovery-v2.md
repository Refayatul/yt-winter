# BTO source discovery v2

The research lane must not treat Wikipedia title matching as the quality gate. Discovery may be broad; evidence acceptance remains strict.

1. Search multiple semantic queries for related Wikipedia articles.
2. Use search results only to discover evidence candidates, never as evidence themselves.
3. Prefer authority hosts (government, university, museum/standards hosts already accepted by the BTO builder).
4. Production-ready status still requires reachable sources, verbatim quotes, narration-to-fact support, numeric traceability, and the existing BTO quality gate.
5. Rate limits remain controlled by the research workflow retry/pause settings.
