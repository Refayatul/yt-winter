# ProfitDecoded: what still blocks a scheduled, unattended documentary run (2026-10-11)

**Full automation is NOT complete.** No complete unattended dry run has passed. The existing path is `.github/workflows/profitdecoded-produce.yml` → `scripts/profitdecoded/auto-produce.js` → `core/profitdecoded/auto/produce.js`. Its schedule is off until `vars.PD_AUTO_SCHEDULE == 'true'`.

What already works unattended:
- topic selection and eligibility;
- research with page verification (cached), and the research gate;
- budget reservation, ledger and single-use approvals;
- free narration (Kokoro);
- the old still-image renderer;
- the dry-run assessment.

Approval gates stay for every paid call and for publishing.
